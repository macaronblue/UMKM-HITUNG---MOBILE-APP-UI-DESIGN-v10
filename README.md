# UMKM Hitung

Mobile web app to help Indonesian UMKM owners calculate profit, break-even point, and manage daily cash flow.

## About
Many small business owners in Indonesia still track finances manually using notebooks or Excel. This leads to calculation errors and wasted time. 

UMKM Hitung solves this by providing a simple, mobile-first calculator that works offline in the browser. No installation needed.

## Features
- **Profit Calculator**: Calculate profit by subtracting costs from revenue
- **Break-Even Calculator**: Find out how many units you need to sell to break even
- **Cash Flow Tracker**: Log daily income and expenses with automatic balance tracking
- **Offline Support**: Data saved locally using browser localStorage
- **Bahasa Indonesia**: Interface in Indonesian for local users

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## How to Use
1. Open the live demo link on your phone or computer
2. Choose a calculator from the home screen
3. Input your data and tap "Hitung"
4. Data is saved automatically in your browser
